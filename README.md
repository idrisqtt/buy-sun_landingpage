# BUY SUN Landing Page

Landing page для BUY SUN с hero секцией, адаптированной под все размеры экранов.

## Установка

```bash
npm install
```

## Запуск разработки

```bash
npm run dev
```

## Сборка

```bash
npm run build
```

## Структура

- `src/Hero.jsx` - компонент hero секции
- `src/Hero.css` - стили hero секции с пропорциональным масштабированием
- `public/man1.png` - изображение для hero секции

## Сервер заявок

Формы и анкета отправляются на сервер из папки `server/`: он хранит заявки
в базе и передаёт их в Битрикс24 и на почту. Запуск и настройка: `server/README.md`.
При `npm run dev` сайт пересылает `/api` на сервер `127.0.0.1:3001`.

## Сервер

Сайт и сервер заявок работают на VPS PS.kz. Установка, обновление из GitHub,
резервные копии и уведомления о сбоях: `deploy/README.md`.
