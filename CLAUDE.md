# Сайт BUY SUN: памятка для Claude

Сайт buysun.kz агентства BUY SUN (трудоустройство в отели Турции). Правки
обычно просит владелец, Ахмед. Он не программист: отвечай по-русски, простыми
словами, без терминов. Если просьба неясна (какой блок, какой текст), сначала
переспроси, потом правь.

## Как вносить правку

1. Найди блок по таблице ниже, поменяй только то, о чём просили. Остальной текст,
   вёрстку и стили не трогай.
2. Проверь сборку: `npm ci`, затем `npm run build`. Пока она падает, правку не
   отдавай.
3. Коротко опиши по-русски, что изменилось: «было → стало», в каком блоке.
4. Сообщение коммита: `Content: <что изменилось>` по-английски, как в истории
   репозитория. Описание pull request: по-русски, для Ахмеда.

После того как Ахмед одобрит pull request и он попадёт в `main`, сервер сам
обновит сайт примерно за 5 минут. Если сборка не проходит, сервер оставляет
прошлую версию.

## Фото

Ахмед загружает новое фото в репозиторий через GitHub, обычно в отдельную
ветку, и пишет, куда его поставить.

- Для сайта фото переводится в WebP: ширина не больше 1600 px (для небольших
  карточек 800 px), качество около 80, размер файла желательно до 300 КБ.
  Конвертер можно поставить временно (например, `pip install pillow`), но не
  добавляй его в `package.json`.
- Имя файла латиницей, без пробелов. Заменяешь фото — либо перезапиши файл с
  тем же именем, либо поменяй имя в коде и удали старый файл, если он больше
  нигде не используется.
- Исходник, загруженный Ахмедом (большой JPG/PNG/HEIC), в репозитории не
  оставляй: только готовый WebP.
- У картинки должен остаться `alt` с понятным описанием по-русски; у фото ниже
  первого экрана — `loading="lazy"`.
- Видео первого экрана сжато в две версии (540p для телефонов и 720p). Новое
  видео сам не подставляй: попроси Ахмеда передать его разработчику.

## Чего не трогать

Эти части связаны с сервером, базой, анкетами кандидатов и Битрикс24. Ошибка
в них ломает приём заявок. Если Ахмед просит поменять что-то здесь, объясни,
что это работа для разработчика, и ничего не меняй:

- `server/`, `deploy/`, `admin/`, `src/admin/` — сервер, обновления, кабинет менеджеров;
- анкета: `src/ResumeModal.jsx` (вопросы, поля, проверки), `src/anketaPdf.js`,
  `src/canvaPdf.js`, `src/anketaDraft.js`, `src/PhotoField.jsx`, `src/photoUtils.js`,
  `src/pdfFonts.js`, `public/fonts/`. Исключение: явная опечатка в подписи
  или подсказке анкеты, без изменения самих полей;
- `src/api.js` (кроме номера WhatsApp), формы заявок (их отправка на сервер);
- `package.json`, `package-lock.json`, `vite.config.js`, `index.html` — без
  новых библиотек и настроек;
- папка `materials/` — исходники, на сайт не попадают.

Никогда не добавляй в репозиторий анкеты, фото или данные кандидатов, пароли
и ключи.
